\begin{abstract}
\textbf{Context.} Recent work estimates how much of open-source software is written by
AI, using zero-shot detectors, keyword scans and language models as classifiers.
\textbf{Objective.} None has been validated against ground truth on open-source
artifacts, having been benchmarked on news, essays and curated code.
\textbf{Method.} Ground truth needs no human annotation. Contributions opened by
coding agents under their own accounts give a positive set of \PositiveTexts{} texts:
commit messages, pull request and issue text, comments and code diffs.
Artifacts from the same repositories predating ChatGPT give a negative set in which any
detection is an error by construction. We evaluate seven approaches and propagate the
measured errors through the Rogan--Gladen correction.
\textbf{Results.} At the threshold published for software artifacts, Binoculars marks
\PublishedBinoDiffFpr{} per cent of pre-ChatGPT code diffs as AI-written, and over half
of every other type. Calibrated instead to a five per cent error budget, they still rank pre-ChatGPT human text as more machine-written than
agent text, while a classifier we train on the same input separates them well on pull
request descriptions: the signal is there and the instruments miss it. A language model asked to judge authorship marks most pre-ChatGPT bot output
as AI, responding to automation of any kind.
\textbf{Conclusions.} The correction that would repair a published estimate cannot be
applied to most of these instruments: no true prevalence could have produced the rates
they report. Those estimates need remeasuring
rather than adjusting. We also give a provenance vocabulary that records an attribution
with the error rate of its case.

\end{abstract}
