\begin{abstract}
\textbf{Context.} Recent empirical work estimates how much of open-source software is
written by AI, and further studies build on those estimates. They rest on zero-shot
statistical detectors, keyword scans and language models used as classifiers.
\textbf{Objective.} None has been validated against ground truth on open-source
artifacts: all were benchmarked on news articles, essays and curated code. We ask what
they measure on open-source text, and what follows for the published estimates.
\textbf{Method.} We build ground truth without human annotation: agent-attributed
contributions from AIDev give a positive set of \PositiveTexts{} texts across five
artifact genres, and artifacts written in the same repositories before ChatGPT's release
give a negative set in which any detection is an error by construction. Seven approaches
are evaluated and the measured error rates propagated through the Rogan--Gladen
correction.
\textbf{Results.} At the operating point published for this domain, Binoculars flags
\PublishedBinoDiffFpr{} per cent of pre-ChatGPT code diffs as AI-written, and between
\PublishedBinoMinFpr{} and \PublishedBinoMaxFpr{} per cent across genres. Recalibrated
to a five per cent false positive rate, the zero-shot detectors score between
\ZeroShotAurocMin{} and \ZeroShotAurocMax{}, every cell below chance; measured against
contemporaneous human text some of that recovers, but none rises above chance. A
supervised classifier given the same input reaches \CeilingAurocMax{} on pull request
bodies, so the signal is present and the deployed instruments miss it. An instructed
language model flags \JudgeBotFprMin{} to \JudgeBotFprMax{} per cent of pre-ChatGPT bot
output, responding to automation rather than to language models.
\textbf{Conclusions.} Of \CorrectionCells{} detector and genre combinations,
\CorrectionUndefined{} give an undefined correction and \CorrectionOutOfRange{} an
observed rate no prevalence could produce: most published estimates cannot be corrected
rather than merely adjusted. We give a provenance vocabulary that records an attribution
together with the measured error rate of the stratum it came from.

\end{abstract}
