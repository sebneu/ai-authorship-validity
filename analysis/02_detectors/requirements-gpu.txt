# Versions are pinned rather than floated. A detector whose scoring model or tokenizer
# changes between runs produces numbers that cannot be reproduced, which is the failure
# this paper is about.

# Wheels built for CUDA 12.4 carry no sm_120 kernels and fail at load with
# "no kernel image is available for execution on the device". Blackwell needs
# CUDA 12.8 and PyTorch 2.7 or newer -- do not downgrade these two pins.
