# Detector dependencies for the GPU host (H100/H200). Not installed on the laptop:
# the corpus stage runs there and needs none of this.
#
#   python -m venv .venv-gpu
#   .venv-gpu/bin/pip install -r requirements-gpu.txt
#
# Versions are pinned rather than floated. A detector whose scoring model or tokenizer
# changes between runs produces numbers that cannot be reproduced, which is the failure
# this paper is about.

# The allocated GPU is an H100 vGPU (H100L-94C, driver 595.71.05, CUDA 13.2), which is
# Hopper / sm_90 and supported by every recent build. cu128 wheels run on a CUDA 13
# driver because drivers stay backward compatible with older CUDA runtimes.
#
# Keep cu128 rather than chasing a CUDA 13 wheel: it is the well-tested combination and
# nothing in this workload benefits from the newer runtime.
